# LeadAI
LeadAI is a project wwith the purpose of saving time and increasing efficency. This project aims to help teams plan better and more efficeiently. We use a KanBan board as the default, this board can be eddited manully or by the help of an AI agent. This Agent can convert your simple minimal instructions and convert it into a KanBan board with tasks while keeping the skill sets of the memebers of the team into consideration.
